3. Alur Workflow CI GitHub Actions (Retraining Model Otomatis dengan MLflow Project):
   - Set up job
   - Run actions/checkout@v3
   - Set up Python 3.12.7
   - Check Env
   - Install dependencies
   - Run mlflow project
   - Get latest MLflow run_id

4. Perbaikan Sesuai Catatan Reviewer:
   - Menambahkan `set -e` dan `set -o pipefail` pada step `Run mlflow project` agar workflow gagal secara eksplisit jika terjadi error pada eksekusi training, dan tidak memunculkan pesan sukses palsu.
   - Penanganan MLFLOW_TRACKING_URI:
     * Menghapus sanitasi spasi / karakter tak sengaja pada nilai tracking URI.
     * Jika tracking URI mengarah ke localhost/127.0.0.1, runner otomatis menjalankan MLflow tracking server lokal pada runner port 5000 sehingga runner dapat melakukan tracking tanpa terputus 'Connection refused'.
     * Jika tracking URI remote (DagsHub) disediakan pada secret GitHub, workflow akan menggunakan URI remote tersebut.
     * Jika tidak ada tracking URI, workflow menggunakan tracking file lokal (mlruns) runner.
   - Step `Get latest MLflow run_id` mengambil dan menampilkan Run ID, Status, serta seluruh metrik hasil retraining MLflow secara otomatis.
   - Retraining berjalan otomatis setiap ada push ke branch main atau dipicu via workflow_dispatch.
